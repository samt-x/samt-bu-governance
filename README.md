# samt-bu-governance – Styring

Styring og gjennomføring av SAMT-BU (Sammenhengende tjenester for barn og unge): arbeidsmodell, beslutningslogg,
deltakere og tilgang, oppgaver og oppfølging, samlinger.

- **Sider:** [Styring](https://docs.samt-bu.no/styring/) på docs.samt-bu.no.
  Repoet er en Hugo-modul, og `content/` monteres på `styring`.
- **Eier:** kjerneteamet (`samt-bu-core-team`). Andre bidrar med «Foreslå endring» på nettstedet.
- **Historikk:** sidene lå i `samt-bu-docs` under `content/prosjektstyring/` til 2026-11-15, og historikken derfra
  er tatt med. Gamle adresser (`/prosjektstyring/…`) sendes videre.

Bakgrunn: [solution-samt-bu-docs#82](https://github.com/samt-x/solution-samt-bu-docs/issues/82) (repo per ansvarsområde).
